# Quick Start Commands

## To Run the Frontend (React App)

### First Time Setup (Only needed once, or after adding new packages):
```powershell
cd pharma-supply-chain\frontend
npm install
```

### Every Time You Want to Run:
```powershell
cd pharma-supply-chain\frontend
npm start
```

The app will open at: **http://localhost:3000**

---

## One-Line Commands (Copy & Paste)

### Start Frontend:
```powershell
cd pharma-supply-chain\frontend; npm start
```

---

## What Happens:
1. Server starts on `http://localhost:3000`
2. Browser opens automatically
3. App compiles (takes 30-60 seconds first time)
4. You're ready to use the app!

---

## To Stop the Server:
Press `Ctrl + C` in the terminal

---

## Notes:
- **First time:** Run `npm install` if you see errors about missing modules
- **Port 3000 busy?** React will ask to use a different port (like 3001)
- **Backend:** If you need the backend, navigate to `pharma-supply-chain\backend` and run `npm start` separately
